# 🏰 천하통일: 팔도 영지전 (SLG Territory Conquest)

> **현실 지명 GIS 행정구역 기반 영지 전략 SLG 안드로이드 모바일 프로젝트**  
> 개발 계획서 v0.3 구현 베이스라인 (Kotlin + Jetpack Compose)

---

## 🎯 게임 기획 및 핵심 메커니즘

1. **현실 행정구역(읍·면·동) 기반 영지 시스템**
   - 대한민국 실제 GIS 법정동/행정동 코드를 기반으로 영지를 생성합니다.
   - 실제 인구 비례로 호족 수 상한(예: 인구 1만 명당 1명) 및 자원/병력 생산 상한을 산정합니다.
   - 한 지역에 복수의 유저 호족이 공존하며, 과반수 연합 및 성주 쟁탈전을 벌입니다.

2. **성주-호족 의회 및 전시 병력 차출·반란 메커니즘**
   - 지역 중심 거점의 성주는 정책(세율, 병력 차출, 전쟁 선포)을 단독 결정하지 못하고 호족 의회 투표를 거칩니다.
   - 성주가 과도한 병력을 징발하거나 독단을 부리면, 반대파 호족들이 연합하여 쿠데타(반란)를 일으킬 수 있습니다.

3. **삼국지식 인재 탐색·등용 및 '재야 인재 위장 잠입 스타팅' (하극상)**
   - 플레이어가 호족이 아닌 **일반 인재(재야/가신)** 신분으로 게임을 시작할 수 있습니다.
   - 다른 유저는 이를 전혀 알 수 없으며, 인재로 시작한 유저는 비밀리에 사병을 육성하고 영지 내 지지도를 높여 **주군을 축출하고 세력을 찬탈(하극상)**할 수 있습니다.

4. **방어 시설 구축을 통한 수성 절대 우위 & GIS 단판 대회전**
   - 호족 장원 목책부터 석성, 산성, 관문 구축 시 수성군 사상자가 최대 80% 격감합니다.
   - 보급선 절단 메커니즘을 적용하여 단순 소모전 없이 무혈 항복을 유도할 수 있습니다.
   - 단순 반복 전투를 배제하고 지형·보급 중심의 단판 전략 대회전으로 승부를 결정짓습니다.

## 🛠 기술 스택 및 아키텍처

- **플랫폼**: Android (Min SDK 26, Target SDK 35)
- **프로그래밍 언어**: Kotlin 2.0+ (선정 사유: Android 공식 언어, 최신 코루틴/플로우 지원, 고성능 타입 세이프티)
- **UI 프레임워크**: Jetpack Compose + Material 3 (선언형 반응형 UI)
- **아키텍처**: Clean Architecture (Domain / Data / Presentation 분리)
- **비동기 처리**: Kotlin Coroutines & StateFlow
- **검증**: JUnit 4 / AndroidX Test

```
com.game.slg
├── core
│   ├── model          # 영지(Territory), 호족(Lord), 인재(Talent), 방어시설(Fortress), 의회(Council)
│   └── engine         # 전투(CombatEngine), 의회(CouncilEngine), 잠입(InfiltrationEngine)
├── ui                 # Jetpack Compose UI 및 시뮬레이션 컴포넌트
└── MainActivity.kt    # 메인 액티비티 진입점
```

### 1. 「연방 붕괴의 그림자: 광교·용인 유민 유입 딜레마」
- 영지·지도 탭에 **긴급 민생 이벤트 카드**가 추가됩니다. 연방 통신·물류망 붕괴로 유민 800명이 매탄동 성문 앞에 몰려든 상황입니다.
- 선택지 A *"임시 거주지 개방 및 식량 배급"* → **식량 -500 · 인구 +800 · 민심 +10 · 문화 명성 +8** (식량 500석 미만이면 선택 불가)
- 선택지 B *"성문 통제 및 선별 수용"* → **자금 +200(관세) · 민심 -12 · 외교 평판 -8**
- UI: `TerritoryScreen` 유민 카드, `SlgGameViewModel.chooseRefugeeCrisis` (`RefugeeCrisisEngine`).

### 2. 「호족 의회의 이면: 히든 인재 야간 밀회 (포섭·숙청·이중첩자)」
- 외교·첩보 탭의 히든 인재 카드에서 **의심도 50 이상**(예: 한도윤 62) 인재에게 **「🌙 야간 밀회: 비밀 서신」** 인터랙티브 이벤트를 엽니다.
- 3지선다: **포섭**(의심도 -30 · 명성 +5 · 첩보력 +10) / **숙청**(자금 +400 · 민심 -8 · 인재 제거) / **이중첩자 역파견**(자금 -150 · 광교동 정보·보급 교란 버프, 적 군량 -200석)
- UI: `DiplomacyScreen` 밀회 카드, `SlgGameViewModel.openNightMeeting` · `resolveNightMeeting` · `exploitDoubleAgent` (`HiddenTalentNightEngine`).

### 3. 「성주(Castellan) 승격 마일스톤 로드맵」
- 영지·지도 탭 상단에 **읍·면·동 호족 → 과반 연합 성주 → 수원시 통합군주** 로드맵 바가 추가됩니다.
- 인접 영지 우호/동맹(원천동 물자 협정 · 광교동 속국 조약 · 용인 수지 상호방위 조약)과 명성 조건(80 → 95)을 채우면 **「👑 성주 승격 의식」 축하 배너**와 **의회 권한 확장 보너스**(+10% → +25%)를 받습니다.
- UI: `TerritoryScreen` 로드맵·의식 배너, `SlgGameViewModel.promote` (`PromotionEngine`).

## 🗺️ 메인 UI 3단 분할 (v0.6)

사용자 요청 — *"메인 UI 의 1/3 크기는 맵을 보여줄수 있게 해줘 전체 맵은 너무 크니 내 영지 기준으로 특정 범위 까지만 보이게 하고 확대 축소 기능을 넣어줘 그리고 나머지 1/3은 현재 상태를 보여주는 용도로 쓰고 나머지 영역에는 서브 메뉴 아이콘을 추가해줘"* — 를 그대로 반영해 메인 화면을 세로 3등분(`Modifier.weight(1f)`)으로 재구성했습니다. 하단 4탭 내비게이션은 서브 메뉴 그리드로 대체되었고, 기존 기능은 하나도 빠지지 않고 상세 화면으로 열립니다. 단위 테스트는 56 → **87개**로 확장되었습니다.

### 1. 상단 1/3 — 내 영지 중심 제한 범위 지도
- 본진 **매탄동(0,0)** 을 중심으로 **hop 거리 2 이내** 영지만 렌더링합니다. 범위 밖 원거리 세력(영통·망포·화성 동탄·용인 기흥)은 그리지 않고 **「범위 밖 4곳」** 배지로만 표시합니다.
- **확대/축소**: 핀치(`detectTransformGestures`) + 화면 우상단 **＋ / － / 내 영지** 버튼. 배율은 **0.7× ~ 2.5×** 로 제한되고, 이동(팬)은 세계 경계(`WORLD_HALF_EXTENT 1.30`)를 넘지 않습니다.
- **영지 탭 선택** → 가까운 노드 1개가 선택되고 중간 패널의 영지 상세가 즉시 바뀝니다.
- 지형지물: 매탄천 하천, 본진→영지 간선 도로, 본진 영향권 **점선 경계**, 지형 표식(▲ 산악 · ≈ 하천), 소유 관계 색상, 지도 가장자리 안개.
- 모델: `core/map/TerritoryMapModel.kt` (`MapNode`, `MapViewport`, `TerritoryMapLayout`), UI: `ui/MainThreePaneScreen.kt` (`TerritoryMapPane`).

### 2. 중간 1/3 — 현재 상태
- 턴/절기(D+14 · 봄), 자금·군량·병력·보급(민심), **선택 영지 상세**(지형·인구·병력·소유자·메모), **승격 진행**(호족 → 성주 → 통합군주, 우호 영지/명성 게이지), **활성 경보·이벤트**(유민 800명, 광교산 정찰대, 원천동 야간 협약, 의회 표결 대기, 한도윤 밀회, 승격 조건 충족, 군량 부족, 적 군량 위기)를 세로 스크롤로 보여 줍니다.
- 경보를 탭하면 해당 서브 메뉴 상세 화면으로 바로 이동합니다.
- 모델: `ui/MainNavigation.kt` (`StatusAlert`, `StatusAlertBuilder`), UI: `CurrentStatusPane`.
