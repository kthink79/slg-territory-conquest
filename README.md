# 🌆 단일 연방의 황혼 — 지역 영지전 (SLG Territory Conquest)

> **현실 행정구역(읍·면·동) 기반 · 2020년대 대한민국 자치구 영지 전략 SLG**
> Kotlin 2.0 + Jetpack Compose · v0.6.0

연방의 예산과 통신이 끊긴 뒤, 기초 자치구가 스스로 경비선을 세운 세계. 플레이어는
한 읍·면·동을 골라 그 지역에서 이미 세력을 운영하던 **리더 한 명을 인계받아**
관할 구역에서 시작하거나, **재야 영웅으로 시작해 리더에게 등용을 청할 수도 있다**.
상대가 사람인지 기계인지는 어디에도 표시되지 않는다(블라인드 원칙). 지휘 레벨이 오를수록 작전 반경이 인접 읍·면·동 →
시·군 전역 → 광역 생활권으로 넓어진다.

---

## 🎬 시작 흐름

1. **인트로 4장면** — 연방 붕괴 → 자치구 독립 → 현대 편제(기갑·드론·방공) → 지역 지휘관 각성.
   터치로 다음 장면, `SKIP`으로 건너뛰기. `📊 정보 → 인트로 다시보기`로 언제든 재시청.
2. **시작 지역 선택** — 시·도 → 시·군·구 → 읍·면·동. 카드마다 인구와 리더 정원 표시.
3. **리더 인계 / 영웅으로 시작** — 지역 인구가 정한 정원만큼 리더가 이미 운영 중이며,
   그중 하나를 골라 병력·자금·보급·명성·거점을 그대로 물려받거나, 재야 영웅으로 시작해
   리더에게 등용을 청한다. 수락·거절은 능력치·명성·세력 필요도로만 정해진다.

- 인트로 시청 여부와 지역·리더·레벨·자원·시설·승격 진행은 자동 저장되어, 앱을 다시 열면 이어서 플레이한다.
- `📊 정보 → 새 게임`으로 저장을 지우고 다른 지역에서 다시 시작할 수 있다.

## 🛡 지역 연합 · 스폰 보호 (신규 유저 보호막)

- 지역(읍·면·동)을 인계받으면 **7턴 동안 같은 지역 AI 리더 전부와 자동 지역 연합**을 맺는다.
  연합 기간에는 지역 안에서 서로 공격할 수 없다.
- 같은 기간 **외부 인접 구역의 침공도 보호막이 막는다** — 방어전은 사상자 0으로 자동 격퇴된다.
- 대외 원정(무인기·교량 작전)은 보호 기간에도 나갈 수 있다.
- 턴은 **절기 진행 1회 = 1턴**으로 줄어들고, 상단·지도·외교 화면에
  `🛡 지역 연합 · 스폰 보호 7턴 남음` 처럼 남은 턴이 항상 보인다. 0이 되면 교전이 열린다.

