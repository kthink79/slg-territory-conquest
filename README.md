# 🌆 단일 연방의 황혼 — 지역 영지전 (SLG Territory Conquest)

> **현실 행정구역(읍·면·동) 기반 · 2020년대 대한민국 자치구 영지 전략 SLG**
> Kotlin 2.0 + Jetpack Compose · v0.2.0

연방의 예산과 통신이 끊긴 뒤, 기초 자치구가 스스로 경비선을 세운 세계. 플레이어는
한 읍·면·동을 골라 그 지역에서 이미 세력을 운영하던 **AI 호족 한 명을 인계받아**
관할 구역에서 시작한다. 지휘 레벨이 오를수록 작전 반경이 인접 읍·면·동 →
시·군 전역 → 광역 생활권으로 넓어진다.

---

## 🎬 시작 흐름

1. **인트로 4장면** — 연방 붕괴 → 자치구 독립 → 현대 편제(기갑·드론·방공) → 지역 지휘관 각성.
   터치로 다음 장면, `SKIP`으로 건너뛰기. `📊 정보 → 인트로 다시보기`로 언제든 재시청.
2. **시작 지역 선택** — 시·도 → 시·군·구 → 읍·면·동. 카드마다 인구와 호족 정원 표시.
3. **AI 호족 인계** — 지역 인구가 정한 정원만큼 AI 호족이 이미 운영 중이며,
   그중 하나를 골라 병력·자금·보급·명성·거점을 그대로 물려받는다. 나머지는 AI로 계속 운영된다.

- 인트로 시청 여부와 지역·호족·레벨·자원·시설·승격 진행은 자동 저장되어, 앱을 다시 열면 이어서 플레이한다.
- `📊 정보 → 새 게임`으로 저장을 지우고 다른 지역에서 다시 시작할 수 있다.

## 🗺 단계별 맵 확장 (안개)

| 지휘 레벨 | 단계 | 열리는 범위 (탕정면 예시) |
| --- | --- | --- |
| Lv.1 | 관할 구역 | 탕정면 내부만 |
| Lv.2 | 인접 구역 | 배방읍 · 음봉면 · 염치읍 |
| Lv.3 | 연접 구역 | 온양1·2동, 천안 불당1동 등 |
| Lv.4 | 시·군 전역 | 같은 시·군 주요 읍·면·동 |
| Lv.6 | 광역 생활권 | 인접 시·군 |
| Lv.8 | 전국 연결망 | 연결된 모든 거점 |

- 경험치: 작전 성공 +70 / 손실 +35, 절기 +40, 의회 +15, 시설 +10, 승격 +60.
- 잠긴 거점은 지도에 안개(🔒)로 표시되고 탭으로 선택할 수 없다.
- Lv.1에서는 관할 구역 방어전만 가능하고, Lv.2부터 인접 구역 작전이 열린다.

- 건설 시설: 지휘통제실 · 드론 격납고 · 방공 레이더망 · 물류 허브 · 스마트 방호망 ·
  통신·사이버 정보국 · 민방위 지원센터 · 야전 의무지원대.
- 4대 테크트리: 내정(관제센터·스마트 민원·재정·데이터) / 과학기술(통신·드론·GIS·AI 지휘) /
  문화(커뮤니티·안전교육·언론·브랜드) / 군사(기동보병·기갑·화력통제·드론·방공 통합).

## 🏛 정치 · 외교 · 시나리오

- 호족 의회: 경비 인력 소집 · 특별 조례 · 방호 시설 증설 · 무력 대응 결의 표결, 반대 65%면 연합 불복.
- 승격 로드맵: 거점 호족 → 연합 대표(우호 2·명성 80) → 광역 통합군주(우호 3·명성 95).
- 첩보·외교: 불가침/상호방위/속국 조공, 정보 공작, 이중첩자, 야간 밀회(포섭·경질·재파견).
- 사건: 이재민 800명 통제선, 야간 물류 협약, 무인기 정찰조.
- 절기: 봄 지방세 → 여름 재난 대응 → 가을 결산 → 겨울 유지비.

## 🛠 기술 스택

- Android (minSdk 26, targetSdk 35), Kotlin 2.0, Jetpack Compose + Material 3
- Clean Architecture (core/model · core/engine · core/region · core/map · ui)

```
com.game.slg
├── core
│   ├── region   # RegionCatalog(52개 읍면동) · LordCapacity · CommandProgression · AiLordGenerator
│   ├── model    # Territory · Lord · CombatArm · ForceComposition · FacilityType · Fortress
│   ├── engine   # ModernBattleEngine · FacilityEngine · CouncilEngine · Diplomacy · Season
│   └── map      # TerritoryMapLayout(단계별 안개 배치) · MapViewport
├── ui           # 인트로 · 지역 선택 · 호족 인계 · 메인 지도 · 4탭 상세 화면
└── MainActivity.kt
```
